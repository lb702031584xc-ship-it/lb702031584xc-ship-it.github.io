About GameVault

GameVault builds data tables for games that are growing fast enough that nobody has written the numbers down properly yet. Right now there is one: an income table for Steal an Egg.

Where the numbers come from

Pet stats — rarity, income per second, grow time and harvest reward — are read from the community-maintained Steal an Egg wiki, which publishes them under CC-BY-SA. Each tool page links back to the exact source it was built from and shows the date it was fetched.

Anything on a page that is not a published stat is calculated by this site, and the page says so. The $/day column, for example, is income per second multiplied by 86,400.

What this site does not do

  • No invented numbers. If a value is missing in the source, the table shows a dash rather than a guess.
  • No fake codes pages. Games without a code system get no codes page, because a page that promises something that does not exist wastes your time.
  • No trade values presented as fact. Trade values are opinions that move hourly; they are not published and cannot be checked.

How to read a table

  1. Sort by the column that matches your question — $/day for passive income, grow time for fast turnaround.
  2. Use the search box to jump to a specific pet instead of scrolling.
  3. Check the fetch date under the title. A table that is a month old is a different table.

Found a number that is out of date or wrong? The wiki is the source of truth: fix it there and the next fetch will pick it up.

All games are embedded from their original publishers and remain the property of their authors.
